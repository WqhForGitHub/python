# 54. GUI 图片查看器

纯 Python 实现的图片查看器 Demo，仅依赖标准库 `tkinter`，无需安装 Pillow 等第三方库。

## 运行

```bash
python image_viewer.py
```

## 支持格式

由于使用 tkinter 内置的 `PhotoImage`，仅支持以下格式：

- PNG（`.png`）
- GIF（`.gif`）
- PGM（`.pgm`）
- PPM（`.ppm`）

> 如需支持 JPG / BMP / WEBP 等格式，可改用 `Pillow`（`PIL.ImageTk.PhotoImage`），但那样就不再是"纯标准库"实现了。

## 功能

- 打开单张图片或整个文件夹（自动加载文件夹下所有受支持的图片）
- 上一张 / 下一张
- 放大 / 缩小（整数倍）/ 原始大小 / 适应窗口
- 显示状态栏：文件名、序号、原始尺寸、当前缩放百分比
- 滚动条支持（图片大于窗口时可拖动浏览）

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开图片 | `Ctrl + O` |
| 打开文件夹 | `Ctrl + D` |
| 上一张 | `←` |
| 下一张 | `→` |
| 放大 | `+` 或 `=` |
| 缩小 | `-` |
| 原始大小 | `0` |
| 适应窗口 | `F` |

## 实现要点

- `tk.PhotoImage` 的 `zoom(n)` / `subsample(n)` 用于整数倍放大/缩小；
- 用 `Canvas` + 滚动条展示图片，支持画布大于窗口时滚动；
- 监听画布 `<Configure>` 事件，将图片在画布中居中显示。
