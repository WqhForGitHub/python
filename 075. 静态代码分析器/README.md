# 词法分析器（手写状态机版）

> 注：根据用户指示，本 demo 放置在「75. 静态代码分析器」目录下。
> 这是一个**独立**实现，使用字符级状态机，**不**使用正则；与项目其它目录中的 `lexer.py` 不共享代码。

## 识别能力
- 整数 / 浮点（含 `1.5e-3`） / 十六进制 `0xFF` / 二进制 `0b1010`
- 字符串：双引号 / 单引号，带转义 `\n \t \r \\ \' \" \0`
- 标识符 / 关键字（C 风格列表）
- 运算符 / 标点：`+ - * / % = == != < <= > >= && || ! ~ ^ & |`
  `+= -= *= /= %= ++ -- -> => :: .. ... << >> **` 以及单字符 `( ) { } [ ] , ; . : ?`
- 行注释 `//`、块注释 `/* ... */`
- 出错时附带行内容与指针位置

## 用法
```bash
python lexer.py            # 内置 demo
python lexer.py myfile.src # 自定义文件
```
